# PRD

## Primary target users
Policy analysts; program planners; capacity-development managers; evaluators; decision makers; local governments; academics.

## Core user journey
Select period/region → inspect support score → inspect why → inspect evidence → inspect intervention/capacity → ask Copilot.

## MVP features
1. Overview.
2. Support priority map.
3. Why analysis.
4. Intervention & capacity.
5. Evidence/lineage.
6. AI Copilot.
7. Data quality/confidence.

## Non-goals
SR location selection, construction/land planning, operational scheduling, institutional production governance.

## Acceptance
Real data loads from Drive; scores are reproducible; recommendations are evidence-linked; Copilot is grounded; secrets are externalized; dashboard remains usable without Gemini.
