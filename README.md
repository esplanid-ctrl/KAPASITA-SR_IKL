# KAPASITA-MVP
## AI Policy Intelligence untuk Penguatan Layanan Pendidikan Inklusif dalam Konteks Sekolah Rakyat

MVP kompetisi LAN Datathon 2026. KAPASITA mendemonstrasikan alur:
**Data → Diagnosis → Support Priority → Policy Intervention → Capacity → AI Explanation**.

### Scope terkunci
- Sekolah Rakyat adalah konteks kebijakan; MVP TIDAK menentukan lokasi operasional Sekolah Rakyat.
- Fokus: layanan pendidikan inklusif, intervensi kebijakan, dan penguatan kapasitas aparatur/tenaga pendidikan.
- Tidak ada external expert validation atau pilot study sebagai prasyarat kompetisi.
- Target pengguna: analis kebijakan, perencana program, pengelola pengembangan kapasitas, evaluator, pimpinan/pengambil keputusan, pemerintah daerah, akademisi.
- AI merekomendasikan; manusia memutuskan.

### Sumber data
Data dan dokumen kebijakan dibaca dari Google Drive. Repository tidak menyimpan URL sumber, raw data, atau secret.
